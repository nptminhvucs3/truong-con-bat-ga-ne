Bỏ file âm thanh của bạn (mp3, ogg, wav, m4a) vào đúng thư mục theo sự kiện:

  appear/    Trường Con xuất hiện
  catch/     bắt được gà          (nhiều file thì mỗi lần chọn ngẫu nhiên một file)
  miss/      bắt hụt
  escape/    gà thoát khỏi nồi    (nhiều file thì chọn ngẫu nhiên)
  angry/     Trường Con tức giận  (nhiều file thì chọn ngẫu nhiên)
  cooked/    luộc xong gà
  chase/     khi đang lùa gà
  putInPot/  bỏ gà vào nồi
  sad/       hết lượt không bắt được gà
  bgm/       nhạc nền (nhiều file thì chọn ngẫu nhiên một bài mỗi lần chơi)
  cluck/ flap/ rattle/ lidPop/ boing/ fall/   hiệu ứng nhỏ (gà kêu, vỗ cánh, nồi rung, nắp bật, nhảy, ngã)

Tên file đặt tùy ý, số lượng file mỗi thư mục không giới hạn. Không cần sửa code.
Thư mục trống thì game dùng âm thanh tự tạo có sẵn. Sau khi thêm file, chạy lại `npm run dev` (hoặc build lại).
